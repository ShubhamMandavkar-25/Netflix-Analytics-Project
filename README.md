# Netflix Data Analysis Dashboard

### 📊 Tools Used:
- **Power BI**: Dashboard creation and data visualization
- **Excel**: Data cleaning and preprocessing
- **CSV**: Dataset source

### 🧠 Project Overview:
This project analyzes Netflix content and viewership trends to provide actionable insights. The dashboard includes:
- Total shows and movies released over the years
- Genre-wise distribution of content
- Regional content analysis
- Viewer engagement metrics

### 📁 Files Included:
- `Netflix_Dashboard.pbix` → Power BI dashboard file
- `Netflix_Dataset.csv` → Raw dataset used for analysis
- `README.md` → Project description

### 💡 Key Insights:
- Certain genres dominate Netflix’s content library
- Viewer engagement trends show a peak during holiday months
- Regional content expansion can be aligned with popular genres

### 🚀 How to Explore:
1. Open `Netflix_Dashboard.pbix` in Power BI Desktop
2. Interact with slicers to filter by year, genre, and region
3. Hover over visuals to see detailed metrics

### ⚡ Future Enhancements:
- Add predictive analytics for viewer trends
- Integrate additional datasets (IMDb ratings, Netflix reviews)

## 🚀 How to Use
1. Download the Excel dataset from the `data` folder
2. Open `.pbix` file using Power BI Desktop
3. Explore interactive filters and visuals
